# LVDS adapter

Tested with B089AW01-V.0 and HSD089IFW1-A00-V1.0 on a breadboard.
I'm sure it will work with other displays from old netbooks.

This pcb was not tested yet!

Do NOT build if you're not confident in debugging electronics.
The LVDS cable needs to be hand made, there is no commercially available cable with this layout.
I plan to build mine using the cable from the original netbook, if and when I'll get the pcb ordered.

Good luck!
